        <Txt Lang="da-DK">
          <Contents>I kurset vil vi studere de grundlæggende elementer i indlejrede systemer og den grundlæggende arkitektur i en mikrocontroller, dens funktioner, og hvordan vi kan programmere den ved hjælp af C-programmeringssproget. Til dette vil vi studere de grundlæggende principper i C-programmeringssproget, men også mere avancerede funktioner som hukommelsesstyring, som er nyttige i forhold til mikrocontroller-programmering.
Vi vil anvende de lærte færdigheder i et projekt med 3-4 studerende.

Kurset starter med forelæsninger om C programmeringssproget med øvelser. Så indtroducere vi microcontrolleren and forskellige komponenter og hvordan de interagere med microcontrollere forklares. Forelæsningerne varer den første uge, hvorefter gruppeprojektet vil komme i fokus. Grupper skal bygge et indlejret system og iterere på det for at øge dets evner og udnyttelse af kursuselementerne.</Contents>
          <Teaching_And_Learning_Methods>Forelæsninger og projekt</Teaching_And_Learning_Methods>
          <Course_Objectives>Indlejrede systemer udgør en stor del af moderne computer systemer. I dette kursus vil vi udforske grundlæggende elementer af indlejrede systemer baseret på mikrocontrollere ved at studere deres arkitektur, og hvordan man programmerer dem. Vi vil arbejde med et praktisk projekt for at anvende og evaluere kursets læringsmål og demonstrere potentialet af mikrocontrollere.</Course_Objectives>
        </Txt>
        <Txt Lang="en-GB">
          <Contents>In the course, we will study the fundamental elements of embedded systems, electrical and electronic components, and the basic architecture of a microcontroller, its features, and how we can program it using the C programming language. To this end we will study the basic principles of C programming language but also more advanced features like memory management which are useful towards microcontroller programming. 
We will apply the studied skills in a group project of 3-4 students.

The course starts with lectures on the C programming language with excercises. Then the microcontroller is introduced and various components and how they interact with the microcontroller are explained. Lectures will last for the first week, after which the group project will be in focus. Groups must build an embedded system and iterate on it to successively increase its capability and utilization of course elements.</Contents>
          <Teaching_And_Learning_Methods>Lectures and project</Teaching_And_Learning_Methods>
          <Course_Objectives>Embedded systems constitute a large part of modern computing systems. In this course, we will explore the fundamental elements of embedded systems based on microcontrollers by studying their architecture and how to program them. We will work on a hands-on project to apply and evaluate the course learning objectives and to demonstrate the potential of microcontrollers.</Course_Objectives>
