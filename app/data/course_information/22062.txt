        <Txt Lang="da-DK">
          <Contents>Dette kursus introducerer kernemetoder inden for medicinsk datavidenskab med fokus på praktisk analyse af sundhedsdata fra den virkelige verden efter god programmeringspraksis. De studerende vil arbejde med elektroniske patientjournaler, fysiologiske signaler (f.eks. EKG, EEG) og medicinske billeder (f.eks. røntgenbilleder) for at lære, hvordan man håndterer almindelige udfordringer som støj, ulige fordeling af klasser, og distributionsskift.
Centrale emner omfatter grundlæggende statistik (statistiske tests, korrektion for multiple tests, effektstørrelser), signalbehandling (resampling, filtrering), datavisualisering og maskinlæring (logistisk regression, beslutningstræer, ensemblemodeller, krydsvalidering). Kurset dækker også modelforklaringer og introducerer kliniske anvendelser og dataformater (f.eks. EDF). Disse emner vil blive dækket af seks individuelle programmeringsopgaver.</Contents>
          <Teaching_And_Learning_Methods>Forelæsninger samt øvelser</Teaching_And_Learning_Methods>
          <Course_Objectives>Målet med kurset er at sætte dig i stand til at behandle medicinske data fra det virkelige liv ved hjælp af signalbehandling og maskinlæringsteknikker. Der vil blive lagt vægt på praktisk behandling af data, der er indsamlet i forbindelse med patientpleje, såsom tabeldata fra elektroniske patientjournaler, medicinske signaler og billeder. Desuden introduceres udfordringer, der opstår, når man arbejder med medicinske data, såsom manglende data, ulige fordeling af klasser, forskydninger af fordelinger mellem datasæt, bias, og artefakter, samt værktøjer til at modarbejde disse udfordringer.
Dette kursus vil udbygge dine færdigheder i programmering med Python og introducere dig til nye biblioteker. Du vil lære ”Best Practice” i anvendelsen af relevante datastrukturer, distribueret versionskontrol osv. Du vil udvikle evnen til kritisk at vurdere datakvalitet og model præstation gennem validerings-, fortolknings- og forklaringsteknikker.</Course_Objectives>

        <Txt Lang="en-GB">
          <Contents>This course introduces core methods in medical data science with a focus on practical analysis of real-world healthcare data following good programming practices. Students will work with electronic health records, physiological signals (e.g. ECG, EEG), and medical images (e.g., X-rays) to learn how to handle common challenges such as noise, class imbalance, and distribution shift.
Key topics include basic statistics (statistical tests, correcting for multiple testing, effect sizes), signal processing (resampling, filtering), data visualization, and machine learning (logistic regression, decision trees, ensemble models, cross-validation). The course also covers model explainability and introduces clinical applications and data formats (e.g. EDF). These topics will be covered in six individual programming assignments.</Contents>
          <Teaching_And_Learning_Methods>Lectures and exercises</Teaching_And_Learning_Methods>
          <Course_Objectives>The goal of the course is to enable you to process real-life medical data using signal processing and machine learning techniques. Emphasis will be put on hands-on processing of data acquired in patient care, such as tabular data from electronic medical records, medical signals and images. Moreover, challenges arising when working with this data, such as data sparsity, class imbalances, dataset shifts, biases, artifacts etc. and countermeasures will be introduced. This course will expand your programming skills in Python and introduce you to new libraries. You will learn best practices in the use of relevant data structures, distributed version control, and more. You will develop the ability to critically assess data quality and model performance through validation, interpretation, and explanability techniques.</Course_Objectives>
          <DTU_Remark>Bachelor students in Biomedical Engineering have first priority.</DTU_Remark>
          <Remark>You are expected to bring a laptop with a Python environment (see https://pythonsupport.dtu.dk/). Specialized packages will be installed during the course. It is recommended to take this course in parallel with 22051 Signals and linear systems in discrete time. If you are interested in more data analysis, the course 02451 Introduction to Machine Learning is recommended in the following spring semester.</Remark>
