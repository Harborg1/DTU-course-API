        <Txt Lang="en-GB">
          <Contents>This three-week project comprises Monte-Carlo simulations of radiation dosimetry and experimental work. The project relates to current research issues in medical applications of ionizing radiation, accelerator dosimetry, or metrology. Problems associated with nuclear reactions (e.g. isotope production) and imaging (e.g. time-of-flight analysis) can be studied. The computations can normally be carried out using the students' own computers. The course consists of the following elements: (i) Lectures (details about the Monte-Carlo code such as TOPAS/GEANT4 and the theoretical basis for radiation dosimetry), (ii) Studying literature related to the project problem (e.g. research papers), (iii) Obtaining physical parameters for the computations, (iv) Measurements and experiments, (v) Modelling, (vI) Student presentations, and (vi) Report writing.</Contents>
          <Teaching_And_Learning_Methods>Lectures and project.</Teaching_And_Learning_Methods>
          <Course_Literature>Software manuals.
IAEA course material.</Course_Literature>
          <Course_Objectives>The main objective of this course is to carry out a project involving Monte-Carlo simulations and experimental work within the field of dosimetry of ionizing radiation.</Course_Objectives>
          <Remark>Depending on the number of students, if may be necessary to split the class into groups.
The students will be introduced to safety procedures as part of the course. 

First week: Lectures on dosimetry and the Monte-Carlo technique. Installation of the software using openTOPAS/GEANT4 on a Virtualbox running the Linux operating system. Define and select project. Presentation of the chosen project.

Second week: measurements and computations. Presentation of the project status.


Last week: Supplementary measurements and computations, as well as report writing. Presentation of final results.

The experimental facilities can be found using the link: www.mrdc.dtu.dk
OpenTOPAS link: https://opentopas.github.io/contact.html
TOPAS link: http://www.topasmc.org/
EGSnrc link: https://nrc-cnrc.github.io/EGSnrc/ (alternative code)</Remark>
