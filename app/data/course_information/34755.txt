        <Txt Lang="da-DK">
          <Contents>Kurset indeholder gruppearbejde og løsning af praktiske udfordringer.
En mobil robotplatform med en grundlæggende funktionalitet og software er til rådighed som udgangspunkt. Denne platform skal innoveres til at kunne deltage performe i den afsluttende konkurrence. Software udvikling i Python er nødvendigt. Den grundlæggende software er i C++ (delvist Arduino) og kan ændres efter behov. Mekanisk design er anbefalet og er nødvendigt for et godt resultat ved konkurrencen.

Gruppesamarbejde og planlægning er en integreret del af kurset (se læringsmål).

Der vil være nogle få korte forelæsninger med bl.a. installation af software værktøjer, den anvendte platform, kalibrering, fejldiagnose etc.</Contents>

          <Remark>Anvendelse af AI er accepteret både i software design og rapporter.</Remark>

        <Txt Lang="en-GB">
          <Contents>The course includes group work and the solution of practical issues. A basic mobile robot platform with some basic functionality and software will be provided. This platform is to be innovated to participate in the final competition. Software development in Python is needed. The base software is in C++ (Partially Arduino) and can be changed as needed. Mechanical design is recommended and needed for a good performance at the competition.

Group cooperation and planning are an integrated part of the course (see the learning objectives).

There will be a few short lectures, such as installing software tools and exercises to learn the fundamentals of the base platform, calibration, fault diagnosis, etc.</Contents>
