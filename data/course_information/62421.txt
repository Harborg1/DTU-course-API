        <Txt Lang="en-GB">
          <Contents>Programming:
- Fundamental programming concepts including variables, data types, expressions, and operators.
- Control structures (selection and iteration).
- Functions and structured procedural program organization.
- Collections and basic data structures.
- File handling and structured data serialization.
- Principles of developing interactive and event-driven applications.
- Basic techniques for debugging, testing, and improving program quality.

Software development:
- Introduction to iterative software development processes and project workflows.
- Use of development environments and version control systems for structured code management.
- Documentation and code organization practices.
- Introduction to responsible use of AI-assisted development tools in programming and debugging tasks.

Modelling:
- Techniques for modelling program logic, workflows, and user interaction using diagrammatic representations.

Fundamentals:
- Basic concepts of computer hardware, memory organization, and program execution.
- Digital representation of information and logical reasoning in computational problem-solving.</Contents>
          <Teaching_And_Learning_Methods>Lectures, classroom discussions, exercises and project based assignments.</Teaching_And_Learning_Methods>

The course focuses on structured procedural programming, understanding program execution, and developing small interactive software applications. It introduces professional development tools and practices, including version control, debugging, testing, and responsible use of AI-assisted development tools.</Course_Objectives>
