Byg et komplet produktionsklart projekt med navnet dtu-course-api.

FORMÅL

Projektet skal hente alle DTU-kurser for studieåret 2026/2027 fra den officielle DTU Kursusbase, gemme dem struktureret i PostgreSQL og stille dem til rådighed via et REST API.

API'et skal bruges som Tool i Microsoft Copilot Studio til en DTU-kursusanbefaler.

Copilot skal kunne:

1. Søge i alle DTU-kurser.
2. Søge efter emner som machine learning, computer vision, physics og optimization.
3. Filtrere på ECTS.
4. Filtrere på kursusniveau.
5. Filtrere på undervisningsperiode.
6. Filtrere på skemagruppe.
7. Filtrere på institut.
8. Filtrere på sprog.
9. Hente komplette oplysninger om ét bestemt kursus.
10. Få officielle source URLs med hvert resultat.

KILDER

Brug officielle DTU-sider som datakilde.

Primær kursusliste:

https://kurser.dtu.dk/CourseList/list/

Individuelle kurser for studieåret 2026/2027 følger strukturen:

https://kurser.dtu.dk/course/2026-2027/{course_number}

Undersøg den faktiske HTML-struktur på siderne før parseren implementeres.

Gæt ikke på CSS-selectors eller HTML-struktur.

Hvis DTU-siden bruger en bagvedliggende offentlig datakilde eller et endpoint, må den bruges efter verifikation. Dokumentér i README, hvor data kommer fra.

Brug ikke uofficielle kursusdatabaser.

IMPORT AF KURSUSLISTE

Implementér en importer, som først læser den officielle samlede DTU-kursusliste.

Den skal:

1. Hente kursuslisten.
2. Finde alle kursusnumre for 2026/2027.
3. Fjerne dubletter.
4. Validere kursusnumrene.
5. Logge hvor mange unikke kurser der blev fundet.
6. Hente den årgangsspecifikke side for hvert kursus.
7. Parse informationen.
8. Validere data.
9. Gemme kurset med UPSERT.
10. Fortsætte selv om et enkelt kursus fejler.
11. Gemme fejlede imports separat.
12. Udskrive en slutrapport.

Slutrapporten skal fx. vise:

Courses discovered: 1450
Courses imported: 1448
Courses updated: 20
Courses unchanged: 1428
Courses failed: 2

Tallene her er eksempler. Brug de faktiske tal.

ROBUST IMPORT

Implementér:

Request timeout.
Retries med exponential backoff.
Rate limiting mellem requests.
Et tydeligt User-Agent.
Logging.
HTTP status validation.
Duplicate protection.
Transaction handling.
Graceful handling af manglende felter.

DTU's server må ikke bombarderes med parallelle requests.

Brug konservativ concurrency eller sekventiel import med passende pause.

Implementér CLI-parametre som:

python -m importer.cli --academic-year 2026-2027

python -m importer.cli --academic-year 2026-2027 --course 02450

python -m importer.cli --academic-year 2026-2027 --retry-failed

python -m importer.cli --academic-year 2026-2027 --limit 20

Parseren skal kunne testes på få kurser før en fuld import.

PARSER

Parseren skal hente og normalisere felterne fra DTU's faktiske kursusside.

Separér HTML-hentning fra parsing.

Denne funktion:

fetch_course_page(course_number, academic_year)

skal returnere HTML.

Denne funktion:

parse_course_page(html, course_number, academic_year)

skal returnere en valideret Course-data-struktur.

Det gør parseren testbar med gemte HTML-fixtures.

Gem relevante HTML-fixtures i tests/fixtures.

Implementér parser-tests mod mindst tre forskellige typer DTU-kurser.

SEARCH API

Implementér:

GET /api/v1/courses/search

Understøt parametrene:

q
academic_year
ects
level
period
schedule
department
language
campus
limit
offset

academic_year skal som standard være 2026-2027.

limit skal som standard være 20.

Maksimum limit skal være 50.

Eksempel:

GET /api/v1/courses/search?q=machine%20learning&academic_year=2026-2027&ects=5&period=E

Søg i:

title
description
content
learning_objectives
prerequisites

Brug PostgreSQL full-text search.

Resultater skal rangeres efter relevans.

Titler skal vægte højere end beskrivelse og kursusindhold.

Søgeord i titel skal derfor give højere score.

Returnér også relevance_score.

COPILOT STUDIO

Lav filen:

connector/swagger.json

Den skal være en OpenAPI 2.0 Swagger-definition beregnet til Microsoft Power Platform Custom Connector.

Eksponér primært to operations til Copilot:

SearchCourses
GetCourse

SearchCourses skal have operationId:

SearchCourses

Beskrivelse:

Search the official DTU course catalogue for academic year 2026/2027. Use this operation when a student asks for DTU course recommendations or searches for courses by topic, ECTS, study level, teaching period, schedule, department, language or campus.

GetCourse skal have operationId:

GetCourse

Beskrivelse:

Retrieve detailed official information about one DTU course for academic year 2026/2027. Use this operation to verify ECTS, course level, teaching period, schedule, prerequisites, examination information and course content before presenting detailed course information.

Swagger-filen skal konfigurere X-API-Key authentication.

COPILOT-OPTIMERING

SearchCourses-response skal være kompakt.

Send ikke lange learning objectives med hvert søgeresultat.

De fulde oplysninger skal hentes via GetCourse.

Copilot-flowet skal derfor være:

User question
→ SearchCourses
→ relevante kandidater
→ Copilot vælger højst fem
→ GetCourse på udvalgte kurser ved behov
→ svar til bruger
